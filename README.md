# E-commerce Customer Segmentation

Python-based customer segmentation project jo e-commerce customers ko unke purchase behaviour ke basis par alag-alag groups mein baantta hai, taaki marketing strategies ko better target kiya ja sake.

## Objective
Customers ke behaviour ko samajhna aur unhe meaningful segments mein divide karna, jisse personalised marketing aur customer retention improve ho sake.

## Tools & Libraries
- Python
- Pandas, NumPy (data cleaning aur analysis)
- Matplotlib, Seaborn (visualization)
- Scikit-learn (segmentation / clustering)

## Approach
1. Data cleaning aur preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature selection aur scaling
4. Customer segmentation
5. Segments ka analysis aur business insights
